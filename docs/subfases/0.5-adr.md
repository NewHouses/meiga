## Decisións e alternativas descartadas

| Decisión | Alternativa descartada | Motivo |
|---|---|---|
| Formato baseado no de Michael Nygard (contexto, decisión e consecuencias), con seccións para as alternativas e as referencias | Texto libre | Todos os ADR teñen a mesma estrutura e compáranse facilmente. |
| ADR que non se reescriben: unha decisión nova substitúe a vella | Editar o ADR cando cambia a decisión | Consérvase o historial de por que se cambiou cada cousa. |
| Referencias a versións concretas do código (etiquetas de git) | Ligazóns á rama principal deses proxectos | As liñas citadas non se moven aínda que o código evolucione. |
| Comprobación automática das ligazóns | Revisalas a man | Cada PR leva documentación; unha ligazón rota detectaríase tarde. |
| Só as ligazóns internas | Comprobar tamén as externas | As externas dependen da rede e de servizos alleos, e farían a CI inestábel. |
| Distinguir maiúsculas nas rutas | A comparación de Windows, que non as distingue | GitHub si as distingue: unha ligazón válida en Windows podería estar rota en GitHub. |

## Como comprobar que todo está ben

### No navegador

1. **A CI pasa.** No [PR #3](https://github.com/NewHouses/meiga/pull/3), os dous *checks* en verde. No rexistro de **Build and test (Windows)**, o paso *Check documentation links* remata con `OK: … relative links checked in … files.`
2. **O índice dos ADR.** Na lapela *Files changed* do PR, abre `docs/adr/README.md` co botón *View file*.

   **Resultado esperado:** a táboa coas sete decisións en estado *Aceptado* e, debaixo, o diagrama de relacións debuxado (Mermaid).

3. **A estrutura de cada ADR.** Abre calquera ADR desde o índice.

   **Resultado esperado:** as liñas *Estado*, *Data* e *Relacionados*, e as seccións *Contexto*, *Decisión*, *Alternativas consideradas*, *Consecuencias* e *Referencias*.

4. **As referencias levan ao código citado.** No [ADR 0002](../adr/0002-windows-e-renderizado-cpu.md), preme a ligazón a `AtlasEngine.r.cpp`.

   **Resultado esperado:** ábrese o código de Windows Terminal v1.25.2733.0 coas liñas 192–201 resaltadas, onde se escolle Direct2D cando o adaptador é por software.

5. **A arquitectura liga cos ADR.** En `docs/arquitectura.md`, a sección 7 ten a táboa dos ADR e cada ligazón abre o seu.

### Na túa máquina

6. **Descarga a rama do PR:**

   ```powershell
   git fetch origin
   git switch f0.5-adr
   ```

7. **Comproba as ligazóns:**

   ```powershell
   .\tools\check-docs.ps1
   ```

   **Resultado esperado:** `OK: 160 relative links checked in 26 files.`

8. **(Opcional) Comproba que detecta unha ligazón rota.** Cambia unha maiúscula nunha ligazón, executa a comprobación e restaura o arquivo:

   ```powershell
   (Get-Content docs\adr\README.md -Raw) -replace '0001-rust.md', '0001-Rust.md' | Set-Content docs\adr\README.md -NoNewline
   .\tools\check-docs.ps1
   git checkout -- docs\adr\README.md
   ```

   **Resultado esperado:** a comprobación falla con estas liñas, e `git checkout` deixa o arquivo como estaba:

   ```text
   docs\adr\README.md:17: target not found (check the letter case): 0001-Rust.md
   1 broken link(s) in the documentation.
   ```
