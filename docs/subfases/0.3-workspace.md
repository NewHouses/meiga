## Decisións e alternativas descartadas

| Decisión | Alternativa descartada | Motivo |
|---|---|---|
| Catro crates | Un único crate | Separar a lóxica pura do código de Windows: probas rápidas, `unsafe` illado e compilación incremental. Ver [Arquitectura](../arquitectura.md#por-que-esta-separación). |
| Versión exacta de Rust (`1.99.1`) | Canle `stable` | Todas as compilacións usan o mesmo compilador. As actualizacións chegan nun PR propio. |
| `lto = "fat"` | `lto = "thin"` ou sen LTO | O LTO *thin* compila máis rápido pero optimiza menos. Só afecta á compilación *release*: a de desenvolvemento segue sendo rápida. |
| `panic = "abort"` | `unwind`, o valor por defecto | Binario máis pequeno e código máis rápido. O custo, que un pánico pecha todo o programa, compénsase coas regras contra `unwrap()`. |
| CRT estático | CRT dinámico, o valor por defecto | Un único `.exe` que funciona sen instalar nada. O binario medra un pouco. |
| Subsistema `windows` só en *release* | Sempre `windows` | Durante o desenvolvemento interesa ver os diagnósticos na consola. |
| Sen fixar `newline_style` en rustfmt | `newline_style = "Unix"` | Os arquivos poden ter CRLF no cartafol de traballo en Windows, aínda que o repositorio garde LF. Con `"Unix"`, `cargo fmt --check` fallaría en local. |
| cargo-deny | Revisar as licenzas a man | Revisión automática en cada cambio, tamén das dependencias indirectas. |
| cargo-about cun modelo propio | Escribir os avisos a man | Os avisos levan o texto e o *copyright* exactos de cada dependencia e actualízanse sós. |
| `THIRD-PARTY-NOTICES.txt` xerado ao empaquetar | Gardalo no repositorio | Un arquivo xerado e gardado no repositorio pode quedar desactualizado. |

## Erro atopado ao documentar

Corrixiuse no mesmo PR: o detalle está en [Código › ferramentas](../codigo/ferramentas.md#toolsthird-party-noticesps1).

## Como probalo

```powershell
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo deny check
cargo build --release

# meiga.exe é unha aplicación gráfica e PowerShell non espera a que remate,
# así que o código de saída obtense con Start-Process -Wait.
(Start-Process .\target\release\meiga.exe -Wait -PassThru).ExitCode   # 0

# Desde unha "Developer PowerShell for VS": as DLL das que depende.
dumpbin /dependents target\release\meiga.exe

# Avisos de terceiros. Agora só levan a cabeceira, porque aínda non hai dependencias externas.
.\tools\third-party-notices.ps1
```

| Comprobación | Resultado |
|---|---|

| Avisos de terceiros | Probados nunha copia do repositorio cunha dependencia temporal: inclúen o texto da licenza e o *copyright*, sen caracteres escapados. |
